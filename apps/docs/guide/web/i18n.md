# 国际化(i18n)

`@snui/vue-web` 内置 naive-ui 风格的 locale 体系:内置 `zhCN`(默认)与
`enUS` 两份完整文案,通过 `<SnConfigProvider :locale>` 注入,后代组件响应式
切换、无需重挂载。

## 基本用法

```vue
<script setup lang="ts">
import { SnConfigProvider, enUS } from '@snui/vue-web';
</script>

<template>
  <SnConfigProvider :locale="enUS">
    <SnUpload />
    <SnLog :log="lines" loading />
  </SnConfigProvider>
</template>
```

不传 `locale` 时一切组件回落内置 `zhCN`,默认渲染与引入 i18n 之前逐字节
一致(向后兼容)。

## 自定义语言包

`SnLocale` 按组件命名空间分组。自定义语言包允许**省略整个命名空间**——
未提供的命名空间整体回落 `zhCN`;已提供的命名空间必须完整(不做逐 key
深合并,避免组件渲染出 `undefined`):

```ts
import type { SnLocale } from '@snui/vue-web';

const deDE: SnLocale = {
  name: 'de-DE',
  Log: { loading: 'Lädt' },
  // Upload / VideoControls / DatePicker / Pagination / Calendar 全部回落 zhCN
};
```

`zhCN` / `enUS` 常量与 `SnLocale` 及各命名空间接口(`SnUploadLocale`、
`SnDatePickerLocale` 等)均从包根导出,可作为翻译底稿。

## 已覆盖的内置文案

| 组件                    | 命名空间        | 内容                                                       |
| ----------------------- | --------------- | ---------------------------------------------------------- |
| `SnUpload`              | `Upload`        | 状态标签(待上传/上传中/已完成/失败)、拖拽区文案、全部 aria |
| `SnLog`                 | `Log`           | 加载指示文案                                               |
| `SnVideoPreview` 控制条 | `VideoControls` | 播放/暂停/静音/全屏标签与 aria                             |
| `SnDatePicker`          | `DatePicker`    | 星期表头、月份单元、面板标题模板、占位符                   |
| `SnPagination`          | `Pagination`    | 总条数、上一页/下一页/跳页/每页条数 aria                   |
| `SnCalendar`            | `Calendar`      | 标题模板、星期标签、今天按钮、aria                         |

标题模板支持 `{y}` / `{m}`(年/月)、`{name}` / `{accept}` / `{total}` /
`{page}` 占位符,由组件负责填充。

::: tip 未覆盖的组件

(`negative-text` / `positive-text`),接 locale 的改造在计划中;其余组件
没有内置文案。
:::
