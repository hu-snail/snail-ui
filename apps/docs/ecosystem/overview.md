# 生态插件总览

生态插件是**独立于核心组件库的官方插件包**：按需安装、不随 `@snui/vue-web`
发布、各自维护版本与边界。每个插件在侧栏的二级分类下提供一页
**文档 + 实时演示**。

与组件的区别：组件解决「一个控件」，生态插件解决「一整块能力域」——
它们像组件一样按需引入，但通常自带样式层、纯函数工具甚至多个子组件。
