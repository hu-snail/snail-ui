## 分类说明

| 分类 | 定位 |
| --- | --- |
| 基础组件 | 按钮、图标、文本、布局等构成页面的原子 |
| 导航组件 | 导航栏、标签页、侧边导航等页面结构 |
| 录入组件 | 表单与各类输入控件 |
| 反馈组件 | 弹层、加载、进度、提示等过程反馈 |
| 展示组件 | 卡片、图片、二维码、表格等数据展示 |
| 业务组件 | 抽奖、刮刮乐、条形码等成套业务场景 |

## 说明

总览页数据与侧边栏分组同源（`.vitepress/utils/overview-data.ts`），新增组件时两侧同步更新。总览同时也是预览路由的首页（`/preview-mp` 无参数时的默认视图）。
