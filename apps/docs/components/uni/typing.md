# Typing 输入中（uni 端）

`sn-typing` 是聊天 / 生成场景的「输入中」指示：跳动圆点 + 可选文案。

## 何时使用

- 聊天等待对方回复的占位气泡
- AI 生成回答 / 客服处理中的过程指示

## 代码演示

### 基础用法

默认文案「输入中」+ 3 圆点；文案可清空只留圆点，颜色 / 数量 / 速度可调。

## API

### Props

| 名称             | 类型     | 默认值      | 说明                                   |
| ---------------- | -------- | ----------- | -------------------------------------- |
| `text`           | `string` | `'输入中'`  | 随圆点展示的文案（空字符串只显示圆点） |
| `dotCount`       | `number` | `3`         | 圆点数量（1-5 自动夹取）               |
| `speed`          | `number` | `350`       | 单点脉动周期（ms）                     |
| `activeDotColor` | `string` | `undefined` | 圆点颜色，默认主色 token               |
| `customClass`    | `string` | `undefined` | 根节点自定义类名                       |
| `customStyle`    | `string` | `undefined` | 根节点自定义样式                       |
