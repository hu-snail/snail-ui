# Internationalization (i18n)

`@snui/vue-web` ships a naive-ui style locale system: complete `zhCN`
(default) and `enUS` locales, injected through `<SnConfigProvider :locale>`.
Descendant components switch reactively without remounting.

## Basic usage

```vue
<script setup lang="ts">
import { SnConfigProvider, enUS } from '@snui/vue-web';
</script>

<template>
  <SnConfigProvider :locale="enUS">
    <SnUpload />
    <SnLog :log="lines" loading />
  </SnConfigProvider>
</template>
```

Without a `locale` prop every component falls back to the built-in `zhCN`,
keeping rendering byte-identical to pre-i18n behavior (backward compatible).

## Custom locales

`SnLocale` is grouped by component namespace. Custom locales may **omit
whole namespaces** — any missing namespace falls back to `zhCN` wholesale;
a namespace you DO provide must be complete (no per-key deep merge, so a
component never renders `undefined`):

```ts
import type { SnLocale } from '@snui/vue-web';

const deDE: SnLocale = {
  name: 'de-DE',
  Log: { loading: 'Lädt' },
  // Upload / VideoControls / DatePicker / Pagination / Calendar fall back to zhCN
};
```

The `zhCN` / `enUS` constants and all namespace interfaces
(`SnUploadLocale`, `SnDatePickerLocale`, …) are exported from the package
root and can be used as translation baselines.

## Covered built-in strings

| Component                                                             | Namespace                                                   | Content                                                                            |
| --------------------------------------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `SnUpload`                                                            | `Upload`                                                    | status labels, dragger copy, all aria labels                                       |
| `SnLog`                                                               | `Log`                                                       | loading indicator                                                                  |
| `SnVideoPreview` controls                                             | `VideoControls`                                             | play / pause / mute / fullscreen labels + aria                                     |
| `SnDatePicker`                                                        | `DatePicker`                                                | weekday headers, month cells, title templates, placeholders, time columns, confirm |
| `SnPagination`                                                        | `Pagination`                                                | total counter, prev/next/jump/per-page aria                                        |
| `SnCalendar`                                                          | `Calendar`                                                  | title template, weekday labels, today button, aria                                 |
| `SnDataTable`                                                         | `DataTable` + `Pagination`                                  | filter confirm/reset, empty state, embedded pagination                             |
| `SnTransfer`                                                          | `Transfer`                                                  | select-all, search, filter and move-button aria                                    |
| `SnDialog` / `SnAlert` / `SnTag` / `SnNotification`                   | `Common`                                                    | close aria labels                                                                  |
| `SnTree`                                                              | `Tree` + `Empty`                                            | expand/collapse aria, default empty state                                          |
| `SnQrCode` / `SnHeatmap` / `SnBackTop` / `SnDrawer` / `SnAvatarGroup` | `QrCode` / `Heatmap` / `BackTop` / `Drawer` / `AvatarGroup` | download, less/more, back-to-top, resize handles, overflow count                   |
| `SnPopconfirm`                                                        | `Popconfirm`                                                | default confirm/cancel labels (props still override)                               |

Title templates accept `{y}` / `{m}` (year / month) plus `{name}` /
`{accept}` / `{total}` / `{page}` placeholders, filled by the components.
