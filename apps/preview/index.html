02

Package architecture

Single-direction dependency graph (AGENTS.md §67). Foundation layer never imports Vue. Vue renderer consumes runtime, not protocol directly.

Foundation
@snui/protocol0.1.0
Framework-agnostic UI contracts. Zod source-of-truth for UISchema, UINode, UIBinding, UIAction, ComponentContract. No Vue, no DOM.
Schema
@snui/schema0.1.0
Validator + Normalizer + Version compat. Thin pass over Zod, adds stable error codes for AI Repair.
→ protocol
Tokens
@snui/tokens0.1.0
Primitive / Semantic / Component cascade. Theme / Style / Density as independent axes. Resolves to CSS variable bindings.
standalone
Runtime
@snui/runtime0.1.0
AUIRuntime facade + Reactive (Vue) adapter + Safe expression engine + ActionRegistry + AppBridge. Lifecycle + Error system.
→ protocol→ schema→ tokens
Renderer
@snui/vue-web0.1.0
Vue 3 mapping for UISchema → DOM. ComponentRegistry + 4 official components (Button · Input · Form · Card).
→ protocol→ schema→ runtime→ tokensvue
Coming
@snui/uni0.0.0
uni-app adapter. Same Protocol / Runtime, host capability boundary for multi-end (iOS / Android / H5 / MP).

Token cascade — Primitive → Semantic → Component

Theme swaps primitive color, Style swaps component shape, Density swaps size primitives. Each layer is independent.
